GOLF SCORE プライバシー

Android Golf Score Manager

ラウンドの一打を、
気持ちよく記録。

GOLF SCOREは、最大4人のスコアとパット数を18ホール分記録できる、Android向けゴルフスコア管理アプリです。

オフライン対応端末内保存最大4人

Features

ラウンド管理に必要な機能

18ホール入力

打数、パット数、OB数、バンカー数をプレーヤーごとに記録します。

自動集計

合計スコアと合計パット数を入力と同時に自動計算します。

履歴管理

過去のラウンドを端末内へ保存し、表示・修正・削除できます。

最大4人

同伴者を含む最大4人に対応し、レディースティーも個別設定できます。

Rakuten GORA API

ゴルフ場を簡単に検索

ゴルフ場名と所在地の検索に楽天GORAゴルフ場検索APIを利用します。取得した情報はラウンド入力を補助する目的にのみ使用します。

楽天GORAおよび楽天ウェブサービスは楽天グループ株式会社のサービスです。本アプリは楽天グループ株式会社が提供・運営する公式アプリではありません。

Data & Privacy

データは利用者の端末内へ

ラウンド履歴、プレーヤー名、スコア、設定情報はAndroid端末内に保存します。アプリ運営者がこれらの情報を収集する仕組みはありません。ゴルフ場検索を実行したときのみ、検索語とAPI認証情報を楽天ウェブサービスへ送信します。
